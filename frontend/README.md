# Modern Business Site — Frontend

Next.js (App Router) client application for the Modern Business platform, styled with Tailwind CSS using a unified dark-slate agency theme.

## Key Features
* **Pages:** Home, About, Services, Portfolio, and Contact (`/src/app`)
* **Shared Layout:** Sticky global navigation bar, footer, and WhatsApp quick-contact integration
* **API Integration:** Connects to the Django REST backend for dynamic service listings and contact form submissions
